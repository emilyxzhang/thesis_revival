# Data

Data files are not included in this repository (PSID terms prohibit redistribution).
To rebuild, download the following into this folder:

1. **PSID Data Center extract** (CDS + main PSID variables): see variable list in `code/` or below.
2. **FIMS sibling map** (`sib_map.csv`): wide format.
3. **FIMS intergenerational map** (`parent_map.csv`): individual to parents, biological and adoptive, long, unbalanced.
4. **CDS time diary**: `dt_psid_CDS_timeDiaryActivity.Rds`, from ICPSR study 165661, V1.
5. **PSID-SHELF**: `PSIDSHELF_1968_2019_LONG.dta`, from openICPSR project 194322.
